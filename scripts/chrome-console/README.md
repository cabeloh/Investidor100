# Script do Chrome Console

Coloque aqui o script `extractor.js` que você roda no console do Chrome para extrair os dados do Investidor10.

Este script será a base para a implementação do scraper automatizado com Playwright.

## Como usar (modo manual atual)

1. Abra o Investidor10 no Chrome e faça login
2. Abra o DevTools (F12) → aba Console
3. Cole o conteúdo de `extractor.js` e pressione Enter
4. Copie o JSON gerado
5. Repita para a segunda conta

## Próximo passo

O conteúdo deste script será convertido para rodar automaticamente via Playwright,
eliminando a necessidade de execução manual.
